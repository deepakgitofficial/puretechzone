# Pure Tech Zone

A modern, high-performance website for a digital agency specializing in Web & Mobile App Development. Built with React and tailored for scalability and user engagement.

## Features

- **Modern UI/UX**: Clean, responsive design with a professional aesthetic using Tailwind CSS.
- **Dynamic Hero Section**: engaging animated visuals and clear call-to-actions.
- **Service Showcases**: Detailed sections for Web Development, App Development, and UI/UX Design.
- **Contact Form**: Functional contact form integrated with Formspree for real-time inquiries.
- **Responsive**: Fully optimized for mobile, tablet, and desktop devices.
- **Custom Branding**: Unique color scheme (#12b2a6) and branding elements.

## Tech Stack

- **Frontend**: React (Vite)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Routing**: React Router Dom
- **Animations**: CSS Animations & Tailwind Classes

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd pureTechZone
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173`.

### Build for Production

To build the application for production:

```bash
npm run build
```
